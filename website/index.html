Everything in one window

Built for people who live in pull requests.

Board, review, merge, ship. MergePro covers the whole loop for every repository you work on, across all of your GitHub accounts.

Board and list, every account

See pull requests from several GitHub accounts and repositories at once, on a board with Draft, Open, Approved and Merged columns or in a sortable list. Group into lanes by organization, repository or author.

Saved views

Start with built-in views and make your own with a compact filter language.

Needs my reviewMy PRsReady to mergeFailing checksStaleAI-authored

Reviews with drafts and rich diffs

Syntax-highlighted diffs in split or unified layout, inline threads, files marked as viewed and pending review drafts that wait until you are ready to submit.

Merge with one popup

Choose the merge method, use the merge queue or auto-merge where the repository supports them, and merge knowing it is guarded by the head commit you reviewed.

Stacked pull requests

A stack sidebar shows where a pull request sits in its chain, and a stack can be merged in order, one verified step at a time.

GitHub Actions

Follow workflow runs and their logs, start workflows from saved presets, and review pending deployments without leaving the app.

Repository browser

Browse code, branches, history, releases and labels for any repository you can access, and open a new pull request from a branch.

Local Git clones

Work in the folders you choose: review changes, stage individual hunks, commit, switch branches, stash, manage worktrees and resolve conflicts.

Menu bar and activity inbox

A menu bar review queue shows what needs you, your open PRs and running workflows. The activity inbox and optional notifications keep you current.

Merge without surprises

Merge exactly what you reviewed.

One options popup gathers everything that matters before a merge. MergePro sends the head commit you saw as the expected head, so GitHub refuses the merge if someone pushed in the meantime.

  • Merge, squash or rebase, as the repository allows
  • Aware of merge queues and auto-merge
  • Stacks merge in order, each step checked

Privacy by design

Your Mac. GitHub. Nothing in between.

There is no MergePro account and no MergePro server. The app talks to GitHub directly and keeps everything else on your Mac.

No backend, no account

MergePro has no servers. Requests go from your Mac to GitHub.

Tokens in the Keychain

You sign in with GitHub's device flow. The token is stored in your macOS Keychain.

No analytics or telemetry

No tracking SDKs, no usage pings, no ads. Cached data lives in a local SQLite database.

Sandboxed

The app runs in the macOS App Sandbox and only opens folders you select.

Keyboard first

FAQ

Questions, answered.

What do I need to run MergePro?

A Mac with Apple silicon running macOS 26 or later, and a GitHub account.

How much does it cost?

Nothing. MergePro is free, with no subscription, no in-app purchases and no ads. The source code is available under the Apache License 2.0.

How does signing in work?

MergePro uses GitHub's OAuth device flow. The app shows a short code, you enter it on github.com and approve access there. Your password never passes through MergePro. The resulting token is stored in your macOS Keychain.

You can add several accounts. Removing an account deletes its Keychain item and cached data; GitHub keeps the authorization until you revoke it in your GitHub application settings.

Does it work with GitHub Enterprise Server?

Not today. MergePro currently works with accounts on github.com. GitHub Enterprise Server hosts are not supported yet.

Where is my data stored?

On your Mac. Access tokens are kept in the macOS Keychain, and pull request and repository data is cached in a local SQLite database inside the app's sandbox container. There is no MergePro server, and the app contains no analytics or telemetry. Read the privacy policy for details.

Can MergePro change things on GitHub?

Yes, when you ask it to: for example submitting reviews, merging, editing labels or approving deployments. Writes happen only through explicit commands, and the affected item is refreshed from GitHub afterwards.

Where can I download it?

MergePro is coming soon to the Mac App Store. Builds will also be published on GitHub Releases, and you can build it from source today.
